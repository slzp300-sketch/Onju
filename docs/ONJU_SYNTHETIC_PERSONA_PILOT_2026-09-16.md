## 방법과 데이터의 성격

1. 국적별 성격이나 행동을 가정하지 않고 목표 종류, 현재 수준, 가용 시간, 언어와 시간대를 달리했다. 국적 설정은 대표성을 보장하지 않는다.
2. 사람이 할 법한 발언과, 그 발언에서 추출해야 할 구조화 후보 값을 테스트 작성자가 함께 작성했다. 모델이 후보를 올바르게 뽑았는지는 이번 검사 대상이 아니다.
3. `updateGoalBrief`를 실제 실행하고 `loadGoalBrief`로 JSON 저장·복원 경계를 검사했다. 이 로더는 실제 에이전트의 `loadState`에서도 사용된다.
4. 지역 설정·현지 날짜·주 시작일·미입력 일정에서 빈 시간을 만들어내지 않는지를 검사했다. 날짜 재현 기준은 `2026-09-15T23:30:00Z`: 한국은 9월 16일, 두 미국 지역은 9월 15일이다.
5. 한·영 비교 입력은 기간 재질문 문제와 별개로, 정보를 한꺼번에 말하는 경우·기간 미확정·현재 수준 미측정·가용 시간 유동성을 따로 확인했다. 비교 검사용 초기 상태도 가상 데이터다.
6. 원시 결과에는 실제 모델 답변을 `null`, 만족도·재방문·지불 의사를 `null`로 기록했다. 예상 질문은 향후 실제 AI 평가 항목이지 관측된 응답이 아니다.

기존 합성 UI 여정은 독서 예제에 작성된 답변을 반환하는 방식이다. 이를 다섯 명의 서로 다른 AI 대화로 재포장하지 않았다. 이번 결과에 UI 실사용·대화 자연스러움·응답 속도·7일간 행동·시장 수요를 측정했다고 쓰지 않는다.

## 재현된 주요 원인

### P1. 영어 기간은 기록되지만 복원 시 사라짐

- 입력: `I will do this in 8 weeks.`
- 수동 후보: 원문 `8 weeks`, 정규화 기간 `8주`.
- 실제 저장 직후: `{ label: "8 weeks", weeks: 8 }`.
- 실제 복원 후: `period: null`, 부족한 정보가 다시 `period`가 됨.
- 원인: 기간 복원에서 기존 정규화 값을 유지하지 않고 표시 원문을 한국어 기간 파서로 다시 해석한다.
- 영향 추론: 실제 모델이 이 후보를 제출하면 이후 기간을 다시 묻게 되는 조건이 만들어진다. 실제 답변 반복 자체를 관측한 것은 아니다.
- 근거: [goalBrief.ts:146](../logs/sites/onju-web-mvp/supabase/functions/onju-agent-v2/goalBrief.ts#L146), [실제 에이전트 복원 경로](../logs/sites/onju-web-mvp/supabase/functions/onju-agent-v2/agent.ts#L396).

### P1. 영어의 ‘현재 수준 미측정 / 시간 유동적’을 거절

- 입력: `I have never measured my current level.` → `baseline_not_decided`.
- 별도 비교 입력: `My schedule changes every week and my available time varies.` → `capacity_not_decided`.
- 동일 의미 한국어 비교 입력은 통과한다.
- 원인: `unmeasured` 근거를 인정하는 검사가 한국어 표현 중심이다. 가용 시간 비교에서는 해당 정보만 빠진 초기 상태를 사용해 기간 누락에 의한 후속 오류와 분리했다.
- 영향 추론: 사용자가 모른다고 답해도 정보가 저장되지 않아 같은 질문이나 복구 안내로 돌아갈 위험이 있다.
- 근거: [goalBrief.ts:205](../logs/sites/onju-web-mvp/supabase/functions/onju-agent-v2/goalBrief.ts#L205). 에이전트의 후보 필터에도 유사한 한국어 검사가 있어 수정 시 함께 검토해야 한다.

### P1. 영어로 여러 정보를 한 번에 주면 실행 여건 기록 실패

- 입력에는 분야·결과·8주·현재 0권·평일 20분을 모두 포함했다.
- 한국어 후보는 한 번에 저장되지만 영어 후보는 `capacity_requires_grounded_user_evidence`로 거절된다.
- 원인: 시간 여건의 의미 검사가 한국어 중심이고, 갱신 전 상태에서 이미 `capacity`를 기다리던 경우에만 다른 표현을 통과시키는 조건이 있다.
- 실제 에이전트에는 앞단 후보 필터도 있으므로 운영 경로에서 동일한 오류 대신 후보가 누락될 수 있다. 여기서 확인한 것은 하위 함수의 조건부 실패다.
- 근거: [goalBrief.ts:227](../logs/sites/onju-web-mvp/supabase/functions/onju-agent-v2/goalBrief.ts#L227), [agent.ts:713](../logs/sites/onju-web-mvp/supabase/functions/onju-agent-v2/agent.ts#L713).

### P2. 영어의 미확정 기간 후보를 저장할 수 있음

- 입력: `Maybe 8 weeks, but I have not decided yet.`
- 잘못된 모델 후보가 제출된 상황을 가정해 동일 기간 저장을 시도했다.
- 한국어 ‘8주가 좋을까? 아직 미정이야.’는 거절되지만, 영어 입력은 기간으로 받아들인다.
- 원인: 기간 결정 여부를 보호하는 검사에서 영어의 불확실성 표현을 다루지 않는다.
- 해석: 실제 모델이 잘못 판단했다는 결과가 아니라, 그런 후보가 왔을 때 서버가 막지 못하는 보호 경계 문제다.
