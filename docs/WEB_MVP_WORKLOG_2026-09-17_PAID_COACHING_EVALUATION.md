# 온주 원문 코칭 유료 평가 — 총 $2 한도

작성: 2026-09-17 (KST)

## 승인과 범위

사용자가 첫 평가 총한도를 기존 $1에서 $2로 상향했다. 추가 $2가 아니라 총 $2로 적용했다. 이전 사용량 확인 추정 $0.296665와 거절·결과 미확인 보류액 $0.356757을 유지하고, 새 시험 세션에 $1.346578 한도를 적용했다.

공개 함수가 아닌 `onju-agent-openai-eval`만 빌드 `2026-09-17-coaching-guide-15`로 갱신했다. 원문의 사용자 발언 3개를 그대로 순차 입력했고 원문의 ChatGPT 답변은 모델에 보내지 않았다. 이후 원문에 없는 기간·실행 여건·장비·측정 기준을 제공하는 가상 발언 1개를 별도로 구분했다. 마지막 파일 내보내기 요청은 제외했다.

## 발견한 문제

1. **실제 요청의 완료 안정성:** 마지막 턴에서 정보 기록 호출 2회는 응답 사용량이 확인됐지만, 다음 상세 응답 요청은 결과 미확인으로 남았다. 이 요청의 원장상 시작부터 정산까지 약 13초, 사용자 턴 전체는 약 32.6초였다. 수정한 90초 제한보다 짧으므로 단순히 설정된 시간 제한에 걸렸다고 단정할 수 없다. 현 로그는 `ai_outcome_unknown`으로 원인을 합쳐 기록해 전송·본문 읽기·제공자 오류를 구별할 근거가 부족하다.
2. **실행 여건 해석 오탐:** “주 3회 한 번에 30분”을 “주 3회, 1회 30분 가능”으로 요약한 첫 기록 요청이 `capacity_requires_grounded_measurement`로 거절됐다. 같은 뜻을 다르게 표현한 다음 요청은 통과했다. 저장된 실제 응답을 네트워크 차단 상태에서 재생해 확인했으며 추가 API 비용은 없었다.
3. **근거 인용 수정 호출:** 3턴에서도 `goal_evidence_quote_required`에 따른 추가 모델 호출 1회가 있었다. 잘못된 근거를 그대로 저장하지는 않았지만, 단순 기록 단계의 비용과 지연이 늘어나는 지점이다.
4. **가독성:** 질문 전체에 굵은 글씨를 적용하고 항목마다 목적 설명을 길게 붙여 문서보다 설문지 같은 인상이 강했다. 답변 길이만으로 품질이 좋아졌다고 판단하지 않는다.
5. **확인 전 전제:** 3턴에서 집에 철봉이 있다고 확인하기 전에 “철봉 외에”라는 표현을 썼다. 턱걸이를 할 수 있다는 정보만으로 집에 장비가 있다고 전제하면 안 된다.

원문 3턴의 “9는 모르겠어”는 온주의 앞선 질문 번호와 맞지 않는다. 원문 입력은 그대로 유지하되, 해당 참조의 모호성을 다시 확인한 것 자체는 이해 실패로 판정하지 않았다.
