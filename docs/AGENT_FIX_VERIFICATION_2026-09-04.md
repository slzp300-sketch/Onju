# 대화 에이전트 오류 수정·검증 — 2026-09-04

## 수정

- 기존 일정 교체 도구 추가. 지정 요일만 교체하고 다른 요일은 유지한다.
- 부분 부정 표현으로 단계가 종료되지 않도록 명확한 완료 발언만 허용한다.
- 단계 전환은 한 요청에서 최대 한 번만 수행하고, 최종 답변 생성 전에 최신 단계를 전달한다.
- 매 모델 요청에 행동 지침과 최신 사실을 전달한다. 저장된 최근 대화(최대 100개 메시지)를 재생하고 같은 턴의 도구 호출·결과도 함께 전달한다. 이전 Responses ID 유효성에 문맥을 의존하지 않는다.
- 확정된 생활 리듬 일부와 목표 초안은 즉시 저장하고 미확정 정보만 질문하도록 지침을 보완했다.
- 브라우저 자동 저장은 에이전트 처리 중 중단하고 진행 중 저장 이후 요청을 보내도록 순서를 조정했다.
- 평가기는 중간 턴의 상태와 최종 DB 재조회 결과를 검증한다. JSON 속성 순서는 비교에서 제외한다.

## 검증 결과

- 결정론적 단위 테스트 6개 통과: 부분 부정, 명시적 완료, 전체 교체, 요일 부분 교체, 잘못된 수정 거부, 대화 재생.
- 실제 API 회귀 시나리오 4개 통과: 부분 부정, 전체 일정 수정, 수요일만 수정, 부분 정보 저장 및 후속 질문 기억.
- 기존 실제 API 대화 시나리오 13개 전체 실행 통과.
- 목표 초안 저장 지침 최종 보완 후 목표 협의 통합 시나리오 별도 재실행 통과.
- Web MVP 프로덕션 빌드 및 eslint + knip 통과.
- Supabase `onju-agent-v2` 배포 완료. DB 마이그레이션 불필요.

## 범위와 한계

- 테스트는 별도 익명 세션과 합성 대화로 수행했다. 기존 사용자 일정은 테스트에서 수정하지 않았다.
- 과거 오류로 이미 중복 저장된 일정은 임의 삭제하지 않았다.
- 실제 모델은 비결정적이다. 이번 통과가 모든 표현·장기 점검에서의 품질 보장은 아니다.
- 일일 점검·수주간 패턴 분석·외부 활동 로그 연동은 이번 수정 범위가 아니다.
- Git 커밋·푸시는 이번 요청에서 수행하지 않았다.
