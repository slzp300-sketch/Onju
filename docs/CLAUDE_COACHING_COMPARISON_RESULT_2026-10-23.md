## 도구·상태에서 확인한 문제

1. **Claude 도구 재처리와 지연:** 독서 초안 필수 항목 1회, 응답 형식 3회, 학습 가용 시간 근거 3회가 검증에 거절됐다. 기존 검증기가 잘못된 초안을 차단했고 에이전트의 기존 턴 내부 루프에서 수정해 최종 응답은 전달됐다. 통신 자동 재시도나 동일 사용자 턴의 별도 재실행으로 숨기지 않았다. 근본적인 도구 사용 안정성은 아직 개선 과제다.
2. **기존 경로도 검증 오류:** `goal_brief_no_grounded_changes` 2회가 있었다. 최종 전달 성공과 구분해 기록한다.
3. **대화 정정과 구조화 상태의 불일치:** 양쪽 독서의 최종 `brief.capacity`는 화·목 각 20분으로 남았고 답변만 화 10분으로 바뀌었다. 미승인 수정안을 보존하는 것과, 이후 상담이 오래된 가용 시간을 사용하지 않게 하는 것은 별개다. 기존 영어 `brief.capacity`도 주 3회로 남았으며 Claude 영어 기억에는 주 3회와 정정된 주 2회가 모두 `confirmed`로 남았다. Claude 학습도 월수금 기억과 월금 기억이 함께 남았다. 구조화 상태·기억의 최신 사실 반영을 고쳐야 한다.
4. **공통 가용 시간 파싱:** 독서에서 “한 달에 0권이고, … 화요일과 목요일 … 20분”을 근거로 생성한 양쪽 시간 계약의 `weeklyMinutes`가 약 4.615분이었다. 문장에 섞인 기준 기간과 실행 빈도를 구분하지 못한 기존 파싱 문제로 보인다. 주 40분/정정 후 30분과 다르므로 배포 전 별도 회귀 사례로 수정해야 한다. 이번 비교에서 사실을 맞추기 위해 상태를 수동 보정하지 않았다.

위 3·4는 **미해결이며 모델 교체로 해결됐다고 간주하지 않는다.** 원문과 상태를 보존했다. 둘 다 마지막 초안은 null, 목표 카드의 결과·기한·주간 행동은 비어 있었고, 목표 확정 이벤트는 모두 false였다. 실제 운영 DB 저장은 없었다. 따라서 “미승인 목표 확정 없음”은 확인했지만, “장기 기억 정확성 검증 완료”라고 확대하지 않는다.
