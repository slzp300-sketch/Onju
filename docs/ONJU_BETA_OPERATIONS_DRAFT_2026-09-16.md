## 기술 항목은 별도 확인

운영자에게 API 키나 사용자 대화 원문을 다시 붙여 넣도록 요청하지 않는다. 필요한 경우 연결된 환경에서 설정 이름·적용 상태·집계만 최소한으로 확인하고, 비밀값은 문서나 로그에 저장하지 않는다.

- 운영 DB migration ledger와 두 작업본의 번호 충돌을 대조한다. 이번 턴에는 원격 조회·SQL 실행·DB 변경을 하지 않았다.
- 실제 연결된 모델 공급자, 데이터 처리 리전, 호스팅/DB 보관 설정을 확인한다. 어댑터 파일의 존재만으로 그 공급자가 실제 사용자 자료를 처리한다고 단정하지 않는다.
- 마지막 유효 사용 후 30일이라는 **코드상 만료 기준**과 실제 삭제 시점을 구분한다. ‘30일 후 모든 곳에서 완전 삭제’로 안내하지 않는다.
- 서버/클라이언트/캐시 적용 순서, 구버전 세션 복구 안내, 예산 예약·정산과 삭제 방지 기록의 보존을 배포 준비 계약과 대조한다.
