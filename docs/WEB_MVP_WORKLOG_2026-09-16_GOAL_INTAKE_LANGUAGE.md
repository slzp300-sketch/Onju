## 실제 에이전트 경로에서 추가 보완

1. **문맥은 활성화됐지만 저장 도구가 닫힌 상태**: 목표 문맥이 이미 로드되어 있다는 이유로 `route_request`가 거절되어 `record_goal_brief`까지 사용할 수 없었다. 해당 도구가 아직 열리지 않았다면 현재 발언의 원문 근거로 활성화를 허용했다. 기존 턴별 요청 횟수 제한·임의 근거 거절은 유지했다.
2. **영어 질문이 한국어 기본 질문으로 교체되는 현상**: 유효한 영어 모델 질문을 유지하고, 잘못된 누락 항목 질문만 영어로 복구하도록 `goalIntakeLanguage.ts`를 분리했다. 기간 영수증·미측정 기본값도 요청 언어에 맞춘다. 한국어 기본 동작은 유지했다.
3. **검사 공백**: Site 에이전트 전체의 엄격한 TypeScript 검사가 기존 무료 검증에 없었다. 새 검사에서 드러난 기존 리터럴 배열/unknown 배열 좁히기 오류 두 곳을 동작 변경 없이 수정하고 상시 검사에 추가했다.

영어 모델 질문의 자연스러움·일정/일일 점검 등 모든 언어 분기까지 완성했다고 주장하지 않는다. 이번에는 목표 정보 기록·복원·후속 질문의 검사된 경로를 보완했다.
