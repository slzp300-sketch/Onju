# 온주 실제 답변 이해력·깊이 평가

작성: 2026-09-17. 사용자 승인: 기존 총 $2 → **총 $3**.

## 결론

**전체 불합격 / 문서급 실제 답변 전달 미검증.** 새 세션에서 원문 사용자 입력 3개에는 정상 응답했다. 부족한 조건을 보충한 가상 4턴은 상세 계획 후보 생성 후 내부 검증 실패와 수정 호출 시간 초과로 HTTP 409가 됐다. 모델의 설명 후보와 사용자가 실제로 받은 답변을 혼동하지 않는다.

원문 ChatGPT 답변은 모델에 전달하지 않았다. 유료 채점 모델은 사용하지 않았으며 내용 검토자는 Codex다. 사람 검수·사용자 최종 승인·다른 분야까지의 품질 보장으로 표시하지 않는다.

## 평가 환경

- 빌드: `2026-09-17-coaching-readiness-19`.
- 평가 전용 함수 `onju-agent-openai-eval`만 21 → 22.
- 공개 `onju-agent-v2` 111 / `onju-agent-v3` 35 유지, 조회로 재확인.
- 공개 Sites·앱·DB 스키마·API 키·타인 세션을 변경하지 않음.
- 제품 코드 변경 없음. 기존 미커밋 변경을 보존했다.
- 첫 3턴: 원문 그대로. 4턴: 기간/빈도/시간/장비/제약/성과 기준을 명시한 가상 입력.

## 관찰

1. 현재 운동 수준, 홈트 선호, 근력과 지구력 목표를 이해하고 답변에 반영했다.
2. 미확인 기간·가능 시간·장비·제약을 묶어서 질문했다. 온주의 대화에는 없는 ‘9번’의 뜻을 지어내지 않았다. 선제 알림을 약속하지 않았다.
3. 3턴은 `goal_evidence_quote_required` 오류를 추가 호출로 수정했다. 최종 응답은 정상 수신했지만 추출은 한 번에 성공한 것이 아니다.
4. 상세 후보에는 12주·주 3회·회당 30분, 세트/횟수/휴식, 이유, 기간별 진행, 기록 예시, 조건부 조정, 중단/복귀가 있었다. 후보의 모든 회차 시간 합계는 30분이었다.
5. 그러나 후보는 앱에서 거절돼 전달되지 않았다. 숫자 합계 외에 18분 달리기 블록을 20분으로 늘릴 때의 재배분, 조건부 중단 규칙을 독립 2분 단계로 표시하는 어색함도 남았다.

## 구조적 실패를 무료로 재현

실제 저장된 모델 응답을 네트워크 차단 상태에서 다시 주입했다. **새 모델 호출 0회**.

- 캡처 모델 입력: 같은 ‘운동’ 분야에 3개 성과 목표.
- `goalBrief.ts:329`: 각 목표 처리 때 같은 분야의 기존 목표를 삭제해 마지막 목표만 남음.
- 상세 모델: 사용자 원문에 있던 세 목표 모두에 행동을 연결.
- `goalBrief.ts:393`: 앞의 두 목표가 내부 목록에서 사라져 `daily_guide_must_link_agreed_result` 발생.
- 같은 오류를 로컬에서 재현. 재현 테스트 통과는 버그 해결이나 품질 합격을 뜻하지 않는다.
- 캡처 약 29초 + 상세 후보 약 56.5초 뒤 수정 호출은 남은 약 24초를 사용하다 timeout. 제공자 오류 로그: `timeoutMs=24002`, `elapsedMs=24003`.
- 전체 4턴 요청 약 110.2초 / HTTP 409 / `ai_outcome_unknown`.

현재 확인한 개선 순서는 동일 분야 복수 목표 보존 및 개별 수정·삭제, 실제 실패 응답 회귀 고정, 폐기되는 캡처 장문 생성 축소, 상세 응답 시간 배분과 계획 단계의 의미 검사다. 목표 연결 검사를 끄는 방식은 해결책이 아니다. 이번은 검증 요청이므로 제품 수정은 아직 수행하지 않았다.
