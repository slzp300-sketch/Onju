# 대화 부담·가독성·스크롤 개선 — 2026-09-04

## 확인한 문제

- 실제 사용 화면에서는 목표를 말하고 있는데 내부 단계가 반복 일정에 남아 있었다.
- 대화 시작 후에도 고정 질문 카드가 남았고, 420px 대화창에 자동 스크롤이 없었다.
- Gowun Dodum과 font-synthesis:none 조합은 강조 표현에 불리했다. 이전 대화 자체에도 문단이 없었다.
- 목표 준비 조건에 기준선, 정체성, 단서 등 선택적 항목까지 포함되어 질문이 길어졌다.
- 경량 모델의 실제 테스트에서 목표 전환 누락, 잘못된 요일 추정, 문자열 형태의 잘못된 weeklyActions가 발견됐다.

## 변경

- 대화 기본 모델을 gpt-4.1-mini → gpt-4.1로 변경. 서버의 ONJU_AGENT_MODEL 환경변수로 재정의 가능. 다른 계획/수정 엔드포인트의 모델은 변경하지 않았다.
- respond 도구로 요약·목록·현재 질문·선택지를 분리하고 서버에서 문단을 구성한다. 최종 응답의 초점과 확정된 목표도 동시에 반영해 말과 실제 단계가 어긋나는 문제를 줄인다.
- 목표는 끝점·수치·기간·주간 행동을 초안으로 먼저 제안하고, 미동의 제안을 확정 사실로 저장하지 않도록 지침과 평가를 추가했다.
- 목표 저장은 명시적인 JSON schema와 서버 검증 사용. 잘못된 주간 행동 형식은 거절한다. 인용 발언은 추적용으로 기록하며 의미 판단/승인을 완전히 보증하는 장치는 아니다.
- 미정 시간은 임의로 채우지 않고 이미 아는 일정부터 진행한다. 반복/회복/예외 일정을 별도 필수 질문으로 강제하지 않는다.
- 계획 시작에 필요한 조건을 결과·판정 기준·기간·유효한 주간 행동으로 축소했다. 기준선과 정체성 등은 필수가 아니다. 생활 리듬이 전혀 없으면 배치 버튼을 열지 않는다.
- 고정 질문은 첫 대화에만 표시. 단계 숫자와 수동 단계 이동을 제거하고 실제 대화로 진행한다. 제안 버튼은 최신 답변 아래에 위치한다.
- 대화 본문은 시스템 글꼴 16px, 더 진한 대비, 굵은 강조, 문단 간격 사용. 이전 긴 답변은 문장 경계에서만 재배치하며 원문 사실은 변경하지 않는다.
- 입력창 고정, 대화 영역 자동 스크롤, 지난 내용 읽기 위치 유지, 최신 대화로 이동 버튼, ResizeObserver 대응. 한국어 IME 입력 완료 Enter는 전송하지 않는다.
- 모바일 시간 지도는 펼치기/접기 제공. 목표 카드는 상세 접기 형태로 분리했다.
- 요청 실패 시 같은 내용 재시도 버튼 제공. 실패한 턴은 자동 저장에서 제외한다. API 429는 요청 한도 안내로 구분한다.

## 검증

- 프로덕션 빌드와 eslint + knip 통과.
- React 렌더링/스크롤/목표 시작 조건 테스트 10개 통과.
- 서버 상태/응답 형식/목표 스키마 테스트 15개 통과.
- 실제 API에서 여러 분야 목표 초안 제안 + stage=5 + 미동의 주간 행동 미저장 확인.
- 실제 API에서 독서 초안 제안 → 사용자 동의 → 주간 행동 저장 확인.
- 실제 API에서 주말 기상·취침을 미정으로 남긴 채 일정 단계로 이동하고 이동/근무를 각각 저장하는 2턴 시나리오 통과.
- 요일별 부분 생활 리듬 3턴 회귀 테스트 통과. 토요일 취침을 일요일에 복제하지 않음.
- 390×844 브라우저에서 가로 넘침 없음, 입력창 노출 확인. 기존 사용자 세션과 분리된 localhost 테스트 세션 사용.
- 실제 브라우저에서 새 응답 후 대화창 bottomGap=0 확인. 이전 대화로 스크롤하면 '최신 대화로' 버튼이 나타나고 버튼을 누르면 다시 bottomGap=0. 1280×900에서도 입력창과 지도가 동시에 보이고 가로 넘침 없음.
- 연속 API 평가 중 429가 발생했다. 이는 통과로 처리하지 않았으며 단일 시나리오로 나눠 재검증했다.
- Supabase onju-agent-v2 배포. DB 마이그레이션 없음. Git 커밋·푸시는 하지 않았다.

## 비용과 남은 한계

- GPT-4.1 입력/출력 토큰 단가는 각각 $2/$8(100만 토큰), 기존 mini는 $0.4/$1.6으로 단가 기준 5배다. 실제 한 대화 비용은 도구 왕복과 캐시 사용에 따라 달라진다.
- 모델 변경과 지침/구조 개선이며, 사용자 데이터로 모델 가중치를 학습한 것은 아니다.
- 사실의 의미적 정확성, 미동의 제안 판별, 장기 대화 품질은 여전히 확률적이다. 이번 테스트는 모든 상황의 품질을 보장하지 않는다.
- 슬롯은 등록된 일정 사이의 빈 구간이지 검증된 여가 시간이 아니다. 이동·식사·휴식을 추가 반영해야 한다.
- 이전에 잘못 저장된 사용자 일정이나 대화 내용은 임의로 삭제하거나 재작성하지 않았다.
- 이번 범위는 setup 대화다. 주간 계획 배치 엔진 자체의 품질, 자정을 넘는 일정 처리, 스트리밍 응답은 별도 검증/개선이 필요하다.
