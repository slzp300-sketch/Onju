## 실제 무과금 점검

기본/시험용 두 경로에서 검사용 빈 세션만 만들었다. 총 14개 요청 모두 기대 결과:

- 올바른 소유 토큰의 세션 생성·조회: HTTP 200.
- 다른 소유 토큰의 메모리 접근 및 대화 요청: HTTP 403 `session_forbidden`; 모델 호출 전 거절.
- 내보내기: HTTP 200, 세션 ID 일치, 소유 토큰·해시 비포함.
- 검사용 세션 삭제와 동일 삭제 재시도: HTTP 200.
- 삭제한 세션의 재접근: HTTP 410 `session_revoked`.

검사용 빈 세션 2개만 정리했다. 실제 사용자 대화는 삭제하지 않았고, 재생성 방지 기록은 남는다. 실제 정상 대화 생성이나 원문 수준 품질까지 검증한 것은 아니다.
