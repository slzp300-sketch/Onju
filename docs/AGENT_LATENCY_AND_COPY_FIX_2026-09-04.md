## 처리한 내용

- **중복 생성 제거:** AI가 주간 행동과 실행 기준을 서로 다른 목록에 두 번 작성하던 구조를 하나로 합쳤다. 저장 형식은 기존 GoalCard를 유지한다. 점검·최소 실행 설명·달성률 분모와 필요 횟수는 코드에서 만든다.
- **여러 분야 누락 방지:** 일·건강·신앙처럼 함께 요청한 분야는 생성 요청에 각각의 필수 칸으로 전달한다. 이미 분야가 구조화돼 있는데 “우선순위”, “감사 기록”에 특정 키워드가 없다는 이유로 재생성하던 과도한 검사도 제거했다.
- **불필요한 재시도 제거:** 완료 문구에 기본 실행 시간과 정확히 같은 시간이 반복되면 중복만 정리한다. 실행률 문구에 숫자가 있고 중복 필드만 비어 있으면 같은 숫자를 사용한다. 서로 다른 수치·범위는 임의로 고치지 않는다. 여러 검증 오류는 한 번에 전달한다.
- **모호한 선택식 행동 정리:** 새 행동을 “운동 또는 스트레칭” 같은 선택지로 확정하지 않는다. 완료 기준이 이미 정확히 한 선택지를 가리키면 그 행동 이름으로 통일하고, 그렇지 않으면 수정하게 한다.
- **회당 단위 보존:** 지원되는 명확한 단일 루틴 입력은 요청한 시간·횟수를 생성 제약으로 고정한다. “주 3회 60분씩”을 30분짜리 두 행동으로 나눠 완료 횟수를 두 배로 세는 문제를 막았다. 상한·복합 변경처럼 해석이 모호한 입력에는 이 고정 규칙을 적용하지 않는다.
- **답변 일관성:** 목표·기간·주간 실행·완료 기준·최소 실행·점검을 한 번씩 표시한다. `tinyStart`의 별도 “매일 시작하기” 문구와 실제 계획으로 오해할 수 있는 기본 한도 안내를 없앴다. 구조화된 카드에서는 최소 실행이 기준이다.
- **화면 상태 안내:** 확정한 목표를 계속 초안이라고 안내하던 문구와 불필요한 “종료일 협의 중” 표시를 수정했다. 생활 리듬이 없어 주간 계획을 만들 수 없을 때는 필요한 정보를 명확히 안내한다.

OpenAI Docs의 [지연 최적화 가이드](https://developers.openai.com/api/docs/guides/latency-optimization)를 참고해 중복 출력과 모델 왕복을 줄였다. [구조화 출력 가이드](https://developers.openai.com/api/docs/guides/structured-outputs)의 필수 필드·객체·수치 제약을 사용해 생성 단계에서 누락과 잘못된 회당 단위를 제한했다. 모델 변경이나 파인튜닝은 하지 않았다.
