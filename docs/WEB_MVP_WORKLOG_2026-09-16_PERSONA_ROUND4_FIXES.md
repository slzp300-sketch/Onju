| 8. 분수 기간 누락 | 소수·반 개월·영어 `and a half` 지원, 직접 추출도 분수 보존 | 두 달 반/2.5 months → 약 11주. 정규화 값의 불일치 차단, 저장·재로드 정수 주 계약 유지 |

## 구현 원칙·호환성

`goalFactIsAsserted`는 원문 포함 여부만 검사하지 않고 **후보가 속한 절, 본인/타인, 과거/현재, 확정/거절/조건/질문**을 공통으로 확인한다. 현재 수준·목표·가용 시간·기간·우선순위에 적용했다. 제외·복원은 대상별 명령 범위 검사를 사용한다.

에이전트는 잘못된 필드 후보만 먼저 걸러 유효한 다른 정보는 기록하도록 했다. 최종 저장 함수도 같은 방어를 수행한다. 예를 들어 잘못 정규화된 날짜와 올바른 현재 수준이 함께 와도 날짜 후보가 다른 정상 정보를 막지 않도록 날짜를 사전 검증한다.

복원 보호는 선택 필드 `freshEvidenceAreas`를 기존 brief JSON에 보관한다. DB 테이블이나 API 도구 입력 스키마 추가는 없다. 복원 후 다시 명시한 사실은 저장하며, 이전에 저장된 동일 사실은 불필요하게 삭제하지 않는다. 이 필드는 전체 대화 변경 이력·영속 턴별 출처 저장소를 구현했다는 뜻은 아니다.

분수 개월은 기존 기간 정책인 연 52주/12개월 환산과 반올림을 따른다. **두 달 반 = 정확한 달력상의 11주**라고 단정하지 않는다. 1.5주 같은 표현도 현재 시스템의 정수 주 계획 단위로 반올림하며, 정확한 마감일을 말하면 날짜 검증을 별도로 사용한다.

이 검사는 보수적인 한영 표현 범위의 로컬 방어다. 언어 모델을 대체하는 완전한 의미 이해 엔진은 아니다. 실제 모델이 올바른 후보를 추출하는지, 잘못된 후보를 버린 뒤 자연스럽게 설명하는지는 별도 실모델 평가가 필요하다.
