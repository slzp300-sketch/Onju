## 결과

루트 웹 MVP와 별도 사이트 작업본에 언어·국가·통화·시간대·주 시작일을 분리한 지역 설정을 연결했다. 기존 한국어 사용자의 저장 데이터는 월요일=0 요일 인덱스와 기록 날짜를 유지한다. 실제 AI 대화 품질 평가, 운영 DB·환경변수 변경, 배포, 커밋/푸시는 하지 않았다.

## 구현 내용

1. `UserRegionalContext`를 언어(`locale`), 국가(`countryCode`), 통화(`currencyCode`), IANA 시간대(`timeZone`), 주 시작일(`weekStartsOn`)로 분리했다. 브라우저 정보는 초기 힌트로만 사용하고 국가를 추정하지 않는다.
2. 지역 설정 화면과 저장·재접속·390px 모바일 레이아웃을 보완했다. 사용자가 수정 중인 값을 다른 탭의 변경이 덮어쓰지 않도록 충돌 안내와 최신값 불러오기를 제공한다.
3. 계획·수정·일일 점검·주간 회고·일일 조정 요청에 지역 컨텍스트를 전달했다. 재시도는 최초 요청의 컨텍스트를 유지하고, 활성 세션의 pending 질문도 현재 언어에 맞게 정리한다.
4. 주 시작일은 표시 순서에만 반영했다. 기존 저장 요일의 의미와 과거 날짜는 시간대 변경으로 변하지 않는다. 레거시 요일 문자열도 영어 화면에서 현재 요일 라벨로 표시한다.
5. 날짜·주간 범위·알림·조용한 시간·중복 전송 방지를 사용자 시간대 기준으로 계산했다. DST의 누락/반복 벽시각을 검사하고, 캘린더 파일에는 지역 시간대와 명시적 `VALARM`을 넣었다.
6. 영어 화면의 주요 빈 상태·오류·일일/주간 안내와 계획 생성·수정 실패 안내를 추가했다. 사용자 목표·일정·대화 원문은 번역 사전으로 바꾸지 않는다.
