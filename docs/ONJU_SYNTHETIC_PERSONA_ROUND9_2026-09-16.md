### 해석 시 구분할 점

1. 미측정 수치, 상대적 미래, 가족 시간, 영어 전체 목표의 현재 실적화는 **잘못된 후보를 저장하는 보호 공백**이다. 모델이 항상 그런 후보를 만든다는 뜻은 아니지만 저장층이 막지 못한다.
2. 한국어 일부 완료, 글자 횟수, 혼합 분수, 세 개 제약은 **정상 정보를 과도하게 거절하거나 가용 시간을 작게 계산하는 문제**다. 정보를 더 물어보거나 실행량을 지나치게 줄일 수 있다.
3. 하루 횟수 문제는 현재 코드가 행동별 발생 횟수를 실행 횟수로 합산하는 계약을 기준으로 했다. 주간 합계는 3회라 주간 10회 안이지만, 월요일 한 날의 2회를 넘는다. 별도 행동을 하나의 세션으로 합치는 기능을 검증한 것은 아니다.
4. 일부 계산 실패가 무제한 초안 허용으로 이어진 것은 아니다. 글자 횟수·세 개 제약은 현재 `unresolved`로 초안을 차단한다.

## 원인 분석과 권장 보완 순서

제품 코드를 읽어 본 결과 다음 경계가 반복적으로 드러났다.

- `goalBrief.ts`: 인용문이 사용자 원문에 존재하는지와 선언된 상태는 검사하지만, `known`으로 제출된 **구체적인 수치가 미측정 발언에서 실제로 뒷받침되는지**는 충분히 확인하지 못한다.
- `goalEvidenceScope.ts`: 주체·미래 표현·목표/완료 키워드를 문장 범위에서 검사한다. 새로운 관계 표현이나 한 문장에 서로 다른 역할의 수치가 들어오면 한계가 있다.
- `goalDays.ts`: 일부 한국어 일간 표기가 숫자에 의존하여 ‘하루 두 번’을 놓친다.
- `goalCapacity.ts`: 혼합 시간의 일부만 읽은 결과가 성공으로 처리될 수 있고, 독립 제약 조합이 두 개 절에 한정돼 있다.
- `goalFeasibility.ts`: 일간 시간과 주간 횟수는 있지만 일간 횟수 검사는 연결되어 있지 않다.

권장 순서는 **① 미측정/임의 수치 저장 방지 → ② 수치별 주체·시점·역할 구분 → ③ 일간 횟수와 다중 제약 보존 → ④ 분수·글자 수량의 완전한 해석**이다. 표현 몇 개만 더 추가하기보다, 후보별 `누구의 정보인지 / 현재인지 미래인지 / 확정인지 미측정인지 / 어떤 수치를 뒷받침하는 근거인지`를 분리하고 저장 단계에서 대조하는 구조를 검토해야 한다. 대화 질문 순서를 고정하자는 제안은 아니다.

이번 요청은 추가 검증이므로 위 제품 개선은 아직 구현하지 않았다.

외부 네트워크를 차단하고 유료 공급자 호출 없이 수행했다. 추가 모델 API 비용 $0은 Codex 이용 요금이나 과거 전체 지출을 포함한 금액이 아니다.

실제 AI의 자연어 추출 성공률·자발적 수정·말투·속도, 이번 20명의 화면 사용성, 만족도·유지율·지불 의향은 측정하지 않았다. 설문 수치와 사용자 인용문을 만들어 넣지 않았다. 기존 UI 자동 검사는 통과했지만 20명이 실제 화면을 사용한 것은 아니다. 유료 평가 29개 시나리오·59개 발언은 실행 계획만 확인했으며 통과 건수에 포함하지 않았다.

운영 사이트·운영 데이터에는 영향을 주지 않았다. 이 보고서는 **고정된 무료 진단 범위에서 확인한 보완 과제**이며, 서비스 전체에 더 이상 문제가 없다는 판정이 아니다.
