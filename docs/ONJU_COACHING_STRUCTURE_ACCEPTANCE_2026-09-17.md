## 범위와 한계

원문의 장점인 충분한 설명, 필요한 정보의 묶음 질문, 조건에 맞춘 구체적인 계획을 목표로 한다. 원문에서 확인 없이 가정한 기간·장비·목표 체중이나 지원하지 않는 자동 연락까지 복제하지 않는다. 코드 검증은 의미 이해·건강 적합성·모든 자연어 표현의 무오류를 증명하지 않는다.

## 구조

1. 일반 목표 정보: 기존 기간·현재 위치·결과·시간·우선순위 기록을 유지한다.
2. 질문별 상태: 질문마다 식별자를 부여한다. 답변 완료·부분 답변·모름·거절을 현재 사용자 원문 근거와 연결한다. 일부 답변으로 다른 질문을 일괄 완료 처리하지 않는다. 잘못된 보조 질문 갱신은 개별 무시하며 별도로 근거가 확인된 목표 정보는 보존한다. 기존 workflow의 단일 업무 상태와 별도로 유지한다.
3. 분야별 준비도: 운동 목표의 환경·자원·제약을 초안 직전에 검사한다. 수행 능력은 장비 보유 증거가 아니다. 모름·거절을 안전 확인으로 바꾸지 않는다. 독서 등 모든 분야에 동일한 필수 설문을 적용하지 않는다. 현재 하드 게이트의 범위는 운동이며 다른 분야는 대화 판단과 기존 일반 목표 검증을 따른다.
4. 설명: 실행 순서와 이유·기간별 진행·기록·조건부 조정·복귀를 구조화해 카드와 대화의 원본을 하나로 유지한다. 같은 설명 반복, 조정 조건/행동 부재, 기록 예시 누락을 최소 검사한다. 이 검사는 설명의 전체 의미와 운동 시간 합계의 정확성을 보증하지 않는다.
5. 승인/저장: 준비도 실패는 새 초안과 확정 목표를 만들지 않는다. 유효한 초안도 사용자가 승인하기 전에는 활성화하지 않는다.

## 무료 검사

- 부분 답변, 질문 순번 변경, 모름·거절, 주제 전환 시 질문 상태 보존.
- 잘못된 질문 ID, 근거 없는 인용, 중복 갱신 거절.
- 장비와 수행 수준 구분, 타인의 조건과 가정/질문을 사실로 사용하지 않기.
- 단답은 대응 질문의 근거로 연결했을 때만 분야 조건으로 인정.
- 일반 목표 정보가 완비돼도 운동 환경/자원/제약 누락 시 초안 차단.
- 빈 설명과 반복 설명 거절, 카드와 상세 설명 일치, 승인·재로딩 보존.
- 기존 전체 회귀·타입·빌드·정적 검사. 주입 응답 검사는 실제 모델 품질과 구분.

## 유료 검사 사전 판정 기준

원문 사용자 입력 3개를 그대로 입력한다. ChatGPT의 참고 답변은 모델에 보내지 않는다. 원문에 없는 기간·가능 시간·장비·제약·관찰 가능한 목표를 보충하는 4번째 발언은 가상 입력으로 별도 표시한다.

필수 통과 조건:

- 정보가 부족한 1~3턴: 조건을 임의로 정한 실행 초안 없음. 새 정보 반영. 필요한 조건 묶음 질문. 단순 반복·모르는 참조의 임의 해석·장비 보유 추측 없음.
- 조건이 모인 4턴: 불필요한 질문으로 계획을 미루지 않기. 목표와 행동을 먼저 제시. 따라 할 순서/분량/휴식, 이유, 진행, 기록 예시, 조건별 조정, 복귀 조건을 설명.
- 사용자 시간·빈도·기간·결과 보존, 대화와 카드 일치, 미승인 상태 유지.
- 전체 평가 응답을 사람이 읽고 판단한다. 길이·키워드나 오프라인 테스트 합격만으로 문서급이라고 판정하지 않는다.
- 예산 부족/전송 불확실/사용량 미확인 시 자동 반복하지 않는다. 검사하지 못한 구간을 미검증으로 표시한다.
