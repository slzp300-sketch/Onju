## 재현된 보완 사항

### 1. 조건부 수칙 검사가 특정 문장 시작에 의존함 — 우선 수정

- 저장 후보: 조건부 중단 수칙을 독립 2분 단계로 배정하면 거절된다.

- 근거: `coachingTiming.ts:20`의 시작 단어 정규식. 새로운 표현의 의미까지 검증하는 구조가 아니다.
- 변형 ID: `conditional-safety-prefixed`.

개선 방향: 실행 단계와 조건부 안전·조정 수칙을 구조적으로 구분하고, 실제 실행·휴식·전환·기록에만 시간을 배정한다. 단어 하나를 정규식에 추가하는 것으로 해결됐다고 판정하지 않는다. 구조화하더라도 자연어 전체의 의미 정확성까지 보장하지는 못한다.

### 2. 본문 시간과 배정 시간이 서로 달라도 통과함 — 우선 수정

- 테스트용 정상 시간 배정은 준비 5분 + 실행 20분 + 정리 5분이다.
- 실행 설명에 **“조깅을 25분 동안 진행한다”**를 추가해도 단계 예산은 20분으로 남아 있고 초안이 표시된다.
- 근거: `coachingTiming.ts:25` 이후 검사는 숫자 배열 합계를 확인하지만 본문 수치와의 일관성은 확인하지 않는다.

개선 방향: 시간의 기준값을 하나로 두고 표시 문구를 그 값에서 생성한다. 본문에 다른 시간·세트·휴식 수치가 있을 때 전체 단계 시간과 충돌하는지 검사한다. 모든 숫자를 단순 합산해 반복 횟수와 시간을 혼동해서는 안 된다.

## 유료 검사로 넘어가는 기준

다음 조건을 충족한 뒤 소규모 유료 검사를 검토한다.

1. 위 3개 결함을 보완하고 같은 오류 변형이 모두 적절히 거절되거나 명시적으로 안전하게 처리된다.
2. 잘못된 원본 후보를 억지로 통과시키지 않는다. 유효한 계획의 정상 표시와 잘못된 계획의 차단을 각각 검사한다.
3. 중요한 설명·목표·가능 시간·기록 기준이 모델 출력 → 저장 → 표시 → 승인 → 재로딩에서 유실되지 않는다.
4. 관련 회귀와 전체 무료 검사에서 새로운 회귀가 없다. 수정한 fixture와 원본 응답의 결과를 계속 분리한다.
5. 실제 검사 전 호출별 최대 예약액이 승인 잔여 예산 안에 드는지 확인한다. 불가능하면 자동 증액하거나 호출하지 않는다.

무료 검사로 새 모델 답변의 품질을 100% 증명할 수는 없다. 여기서의 통과는 **알려진 구조적 결함 없이 유료 실답변 검사를 시작할 준비**가 됐다는 뜻이다. 문서급 실제 답변 판정은 그다음의 결과와 사용자 검수로 판단한다.
