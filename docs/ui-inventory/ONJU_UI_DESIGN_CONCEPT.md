# 온주 손그림 UI/UX 디자인 콘셉트

생성일: 2026-09-02

## 디자인 방향

- 따뜻한 아이보리 종이 위에 색연필로 그린 듯한 가벼운 질감
- 진한 올리브 외곽선과 세이지 그린을 중심으로 로지 피치, 버터 옐로, 페일 스카이를 보조색으로 사용
- 제목에만 손글씨 감성을 약하게 주고, 본문·숫자·입력값은 선명한 한글 산세리프 유지
- 버튼과 카드 모서리는 유기적으로 둥글게 처리하되 터치 영역과 정렬은 정확하게 유지
- 손그림 효과는 브랜드, 완료 보상, 빈 상태, 성장 표현에 강하게 적용
- 입력, 설정, 통계는 질감을 줄여 가독성과 접근성을 우선

## 보드 구성

1. `01-common-controls.png`: 버튼, 입력, 토글, 체크박스, 라디오, 세그먼트 탭, 칩, 배지, 날짜·시간 선택
2. `02-cards-navigation-data.png`: 헤더, 하단 내비, 루틴·목표·소모임 카드, 날짜 스트립, 진행률, 차트, 빈 상태
3. `03-overlays-feedback.png`: 확인 모달, 바텀시트, 토스트, 로딩, 오프라인, 권한, 완료 도장, 업적, 타이머 완료
4. `04-home-routines.png`: 홈, 개인 루틴, 신앙 루틴, 루틴 만들기 화면군
5. `05-goals-stats-review.png`: 목표, 통계, 주간 회고, 나의 나무 화면군
6. `06-groups-profile-auth.png`: 소모임, 모임 상세, 프로필, 로그인·온보딩 화면군

## 적용 원칙

- 이 자료는 방향을 확정하기 위한 디자인 시안이며 앱에 아직 적용되지 않았다.
- 실제 구현에서는 기존 4탭 구조 `홈 · 통계 · 소모임 · 마이페이지`를 유지한다.
- 이미지 생성 시안의 일부 화면 내비 명칭은 구조 설명용이므로 실제 제품 정보 구조를 우선한다.
- 배경 질감은 CSS 또는 작은 반복 텍스처로 구현하고, 모든 컨테이너를 래스터 이미지로 만들지 않는다.
- 생성된 손그림 아이콘과 이모지 자산은 이미지로 사용하되 버튼·입력·카드는 접근 가능한 HTML 요소로 구현한다.
- 최소 터치 영역 44px, 본문 대비 4.5:1, 상태 표시의 색상 단독 의존 금지 원칙을 유지한다.

## 생성 방식

- 내장 이미지 생성 도구 사용
- 스타일 참조: 온주 UI 아이콘 시트와 온주 이모지 시트
- 공통 프롬프트: premium warm colored-pencil, light paper sketch, dark olive outlines, restrained crayon texture, rounded organic corners, mobile-first 390px baseline
