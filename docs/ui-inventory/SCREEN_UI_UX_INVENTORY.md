# 온주 화면별 UI/UX 인벤토리

수집일: 2026-09-02

## 조사 범위

- `src/App.tsx`에 등록된 34개 경로
- 실제 화면을 구성하는 `src/pages`의 28개 페이지 컴포넌트
- 페이지에서 호출하는 공통 UI, 탭, 루틴, 목표, 소모임, 회고 컴포넌트
- 버튼, 입력창, 카드, 탭, 토글, 모달·바텀시트, 빈 상태, 피드백 UI

정적 코드 기준으로 페이지 내부에 직접 선언된 `<button>`은 67개, native 입력 요소는 47개, `Card` 또는 `motion.div` 기반 컨테이너는 98개다. 공통 컴포넌트 내부에서 추가로 렌더링되는 요소는 이 수치에 포함하지 않았다.

## 앱 전체 구조

| 영역 | 주요 화면 | 전역 이동 방식 |
|---|---|---|
| 인증·시작 | 로그인, 회원가입, 비밀번호 재설정, 온보딩 | 독립 전체 화면 |
| 홈 | 대시보드, 개인 루틴 탭, 신앙 루틴 탭, 하루 일기 | 하단 내비 `홈` |
| 목표·성장 | 목표 관리, 월간 목표, 나의 나무, 숲 테마 | 홈에서 진입 |
| 통계·회고 | 통계, 주간 회고, 회고 결과 | 하단 내비 `통계` 또는 홈 배너 |
| 소모임 | 목록, 생성, 상세, 루틴 공유 | 하단 내비 `소모임` |
| 계정·설정 | 프로필, 알림 설정 | 하단 내비 `마이페이지` |

하단 내비는 `홈 · 통계 · 소모임 · 마이페이지` 4개이며, 생성·편집·타이머·회고 같은 집중 작업 화면에서는 숨겨진다.

## 1. 인증·온보딩

### 로그인 `/login`

- UI: 브랜드 로고, 숲 배경, Google·Kakao 소셜 로그인 버튼, 이메일 로그인 전환, 이메일·비밀번호 입력, 로그인 버튼, 회원가입 링크
- 상태: 로그인 진행 로딩, 오류 메시지
- 주요 흐름: 소셜 로그인 또는 이메일 로그인 → 인증 완료 → 온보딩/홈
- 리디자인 대상: 인증 버튼 3종, 입력 필드, 구분선, 브랜드 첫인상 배경

### 회원가입 `/signup`

- UI: 이름, 이메일 아이디, 도메인 선택·직접입력, 비밀번호·확인, 비밀번호 보기 토글, 실시간 검증 상태, 가입 버튼, 로그인 링크
- 상태: 정상·오류·검증 중 표시
- 주요 흐름: 계정 정보 입력 → 유효성 확인 → 가입 → 이메일 확인
- 리디자인 대상: 복합 이메일 입력, 검증 피드백, 비밀번호 조건 표시

### 비밀번호 재설정 `/reset-password`

- UI: 새 비밀번호, 비밀번호 확인, 저장 버튼, 로그인 복귀 링크
- 상태: 링크 만료·오류·완료
- 리디자인 대상: 보안 입력과 완료 피드백

### 인증 콜백 `/auth/callback`

- UI: 로딩 스피너, 처리 상태 문구, 실패 시 복귀 버튼
- 리디자인 대상: 대기·실패 상태 일러스트와 안내 위계

### 온보딩 `/onboarding`

- UI: 다단계 소개 카드, 진행 표시, 건너뛰기, 이전·다음, 사용자 이름 입력, 루틴 유형 선택, 이모지 선택, 루틴 이름 입력, 시간대 선택, 완료 버튼
- 주요 흐름: 가치 소개 → 기본 정보 → 첫 루틴 생성 → 완료
- 리디자인 대상: 단계 인디케이터, 선택 카드, 첫 루틴 생성 경험, 완료 축하 장면

## 2. 홈과 루틴

### 홈 대시보드 `/`

- UI: 인사 헤더, 하루 일기 바로가기, 나무 성장 히어로, 연속 기록·성장 요약, 날짜 스트립, 주간 회고 배너, `개인 루틴/신앙 루틴` 세그먼트 탭, FAB
- 상호작용: 날짜 선택, 어제·오늘 이동, 루틴 완료 도장, 탭 전환, 루틴 추가
- 상태: 오늘/과거/미래 날짜, 완료 애니메이션, 빈 루틴, 동기화 상태
- 리디자인 대상: 정보 밀도가 가장 높은 핵심 화면. 나무·날짜·루틴 카드의 시각적 우선순위 정리가 필요

### 개인 루틴 탭 `PersonalTab`

- UI: 할 일·습관·루틴 그룹, 루틴 카드, 완료 체크, 타이머 시작, 펼치기, 삭제, 날씨/연속 기록/빠른 실행 상태, 빈 상태
- 상호작용: 완료, 타이머, 편집, 삭제, 목록 접기
- 리디자인 대상: 카드 유형 간 구분, 주 행동과 보조 행동 분리, 완료 상태의 손그림 도장화

### 신앙 루틴 탭 `FaithTab`

- UI: 시간대별 아침·점심·저녁 그룹, 말씀·기도 루틴 카드, 완료, 타이머, 묵상 기록 이동, 삭제, 빈 상태
- 상호작용: 시간대 그룹 접기, 완료, 타이머, 은혜 기록
- 리디자인 대상: 시간대별 분위기와 개인 루틴과의 일관성

### 습관 생성·편집 `/habits/new`, `/habits/edit/:id`

- UI: 상단 뒤로가기·저장, 이모지 선택, 이름 입력, 반복 빈도, 알림 토글, 알림 시간·유형 바텀시트, 실행 시점 입력, 타이머 토글·시간 선택, 2분 시작 행동 토글·입력, 최소 행동 입력
- 리디자인 대상: 긴 폼의 섹션 구분, 토글 종속 항목 노출, 저장 버튼 고정 방식

### 개인 루틴 생성·편집 `/personal-routines/new`, `/personal-routines/edit/:id`

- UI: 이모지, 루틴 이름, 실행 시점, 타이머 설정, 포함 습관 선택, 드래그 순서 변경, 소요 시간 바텀시트, 저장
- 리디자인 대상: 루틴 안에 습관을 조립하는 구조를 시각적으로 명확하게 표현

### 신앙 루틴 생성·편집 `/faith-routines/new`, `/faith-routines/edit/:id`

- UI: 이모지, 신앙 루틴 이름, 시간대, 반복, 알림, 실행 시점, 2분 시작 행동, 타이머, 저장
- 리디자인 대상: 습관 폼과 공통화하되 신앙 카테고리의 정서 유지

### 할 일 생성·편집 `/todos/new`, `/todos/edit/:id`

- UI: 뒤로가기, 저장, 이모지 선택, 할 일 입력, 날짜 선택
- 리디자인 대상: 가장 단순한 빠른 입력 화면으로 유지

### 루틴 타이머 `/routine-timer/:id`

- UI: 전체 화면 집중 모드, 현재 단계, 원형 진행률, 재생·일시정지·건너뛰기·완료, 루틴 편집, 단계 카드
- 상태: 실행 전, 진행, 일시정지, 단계 전환, 완료
- 리디자인 대상: 조작 실수 방지, 남은 시간 가독성, 완료 축하

### 습관 타이머 `/habit-timer/:id`

- UI: 일반 집중 모드와 2분 시작 모드, 원형 진행률, 닫기·완료, 시작 행동 안내
- 리디자인 대상: 2분 모드와 본 실행의 전환을 분명하게 표현

### 하루 일기 `/diary`

- UI: 날짜 이동, 기분 선택, 자유 기록 textarea, 자동·수동 저장 상태
- 리디자인 대상: 종이 일기장 같은 입력 경험, 저장 완료 피드백

### 은혜 기록 `/faith-notes`

- UI: 기록 목록, 날짜·내용 카드, 빈 상태, 홈 복귀
- 리디자인 대상: 기록 카드의 손글씨 노트 분위기, 향후 작성 진입점 명확화

## 3. 목표·성장·보상

### 목표 관리 `/goals`

- UI: 주간 목표 섹션, 월간 목표 진입, 목표 요약 카드, 펼치기·접기, 편집·삭제, 연결 루틴, 잠금 상태, 축하 상태
- 리디자인 대상: 주간과 월간의 계층, 목표와 실행 루틴의 연결 표현

### 월간 목표 `/goals/monthly`

- UI: 월간 목표 카드, 생성 FAB/버튼, 펼치기, 목표 습관·시점·장소·대체 행동, 진행 상태, 편집·삭제
- 리디자인 대상: 긴 목표 카드의 요약/상세 단계

### 월간 목표 생성·편집 `/goals/monthly/new`, `/goals/monthly/edit/:id`

- UI: 정체성 문장, 색상 선택, 습관명, 실행 시점, 장소, 빈도, 어려운 날의 대체 습관, 시작 행동, 저장
- 리디자인 대상: 입력 항목이 많아 단계형 폼 또는 섹션 카드 구조가 적합

### 나의 나무 `/streak`

- UI: 나무 성장 시각화, 연속 기록, 단계 카드, 월별 기록, 도장 애니메이션, 보호 방패 안내 모달
- 리디자인 대상: 성장 서사를 강화하면서 숫자 정보의 가독성 유지

### 숲 테마 `/themes`

- UI: 테마 미리보기, 잠금·해금 카드, 적용 버튼, 조건 표시, 상세 미리보기 모달, 분위기 배경
- 리디자인 대상: 테마 차이와 잠금 조건을 한눈에 비교

## 4. 통계·회고

### 통계 `/stats`

- UI: 기간·요약 카드, 달성률, 개인·신앙 루틴 통계, 히트맵/차트, 연속 기록, 일기 기분 분포, 주간 리뷰 난이도 분포, 회고 배너
- 상호작용: 상세 카드 이동, 루틴별 통계 탐색
- 리디자인 대상: 차트와 손그림 스타일의 균형, 정보 위계 및 빈 데이터 상태

### 주간 회고 `/review`

- UI: 단계 진행률, 이번 주 현황, 기분 선택, 한 줄 소감, 루틴 유지·수정·삭제·추가, 빈도·요일·시점·최소 행동 입력, 다음 주 다짐, 공유 그룹 선택, 뒤로·다음·제출
- 주요 흐름: 현황 확인 → 감정 회고 → 루틴 조정 → 다음 주 다짐 → 제출
- 리디자인 대상: 앱에서 가장 긴 단계형 작업. 각 단계의 목적과 완료 조건을 명확히 보여야 함

### 회고 결과 `/review/result/:week`

- UI: 주차 제목, 달성 요약 카드, 별점·기분, 잘한 점·아쉬운 점, 다음 주 다짐, 뒤로가기
- 리디자인 대상: 결과를 성적표보다 따뜻한 주간 편지처럼 표현

## 5. 소모임·공유

### 소모임 목록 `/groups`

- UI: `참여 중/탐색` 탭, 소모임 만들기, 소모임 카드, 공개 모집 목록, 빈 상태와 탐색/생성 CTA
- 리디자인 대상: 탭과 카드 상태, 모집 중·진행 중·완료 배지

### 소모임 만들기 `/groups/new`

- UI: 2단계 폼, 카테고리 선택, 제목·설명, 기간, 공개 토글, 커버 아이콘·색상, 규칙 선택, 이전·다음·만들기
- 리디자인 대상: 커버 미리보기와 공개 범위 설명, 단계 전환

### 소모임 상세 `/groups/:id`

- UI: 헤더, 커버·배지, 설명·기간·멤버 수, 참여·나가기, 관리자 시작·종료, 멤버 진행 카드, 응원, 주간 나눔
- 상태: 비회원, 참여자, 관리자, 모집/진행/완료
- 리디자인 대상: 역할별 CTA가 충돌하지 않도록 상태별 화면 구조 분리

### 루틴 공유 `/share`

- UI: 참여 그룹 선택, `내 루틴/공유 피드` 탭, 루틴 다중 선택, 체크 UI, 메모 입력, 공유 대상 선택 시트, 공유 버튼, 피드 카드, 반응 이모지, 응원 버튼, 공유 취소
- 리디자인 대상: 선택 → 대상 → 공유의 3단계 흐름, 피드 카드와 반응 영역

## 6. 마이페이지·설정

### 프로필 `/profile`

- UI: 사용자 정보 카드, 가입일·사용 시간, 알림 설정·테마·기록 메뉴, 로그아웃, 계정 삭제, 확인 모달
- 리디자인 대상: 일반 메뉴와 위험 행동의 시각적 분리

### 알림 설정 `/notification-settings`

- UI: 전체 알림 토글, 아침·저녁 리마인더 카드, 시간 입력, 미완료 루틴 알림, 권한 상태
- 리디자인 대상: OS 권한과 앱 설정의 차이를 이해하기 쉽게 안내

## 7. 공통 UI 컴포넌트

| 컴포넌트 | 현재 역할 | 리디자인 시 기준 |
|---|---|---|
| `Button` | primary, outlined, assistive, ghost와 크기 변형 | 손그림 테두리·눌림 상태·disabled 규칙 통일 |
| `Card` | 대부분의 정보 컨테이너 | 종이 질감은 약하게, 중첩 카드 남용 방지 |
| `FAB` | 홈·목록의 생성 행동 | 하단 내비와 겹침 및 엄지 도달성 검토 |
| `Badge` | 소모임 상태 등 | 색상 외 형태·문구로도 상태 구분 |
| `EmptyState` | 데이터 없음 안내와 CTA | 페이지별 삽화는 통일된 크기·톤 사용 |
| `ConfirmModal` | 삭제·위험 행동 확인 | 위험도별 버튼 순서와 색상 통일 |
| `DurationPickerSheet` | 시간 선택 | 바텀시트 헤더·확인 방식 공통화 |
| `HabitAlarmSheet` | 알림 시간·유형 선택 | 설정 종속 관계와 권한 안내 포함 |
| `EmojiPickerButton` | 온주 이모지 선택 | 새 300개 라이브러리의 카테고리·검색 UX 유지 |
| `Toast` | 성공·오류·정보 피드백 | 손그림 스타일보다 즉시성·가독성 우선 |
| `LoadingSpinner` | 비동기 대기 | 나무/새싹 성장 모티프 적용 가능 |
| `StampButton/Overlay/Seal` | 완료 보상 | 온주 고유 인터랙션으로 적극 유지 |

## 화면 리디자인 우선순위

1. **P0 공통 시스템**: 헤더, 버튼, 입력, 카드, 세그먼트 탭, 토글, 바텀시트, 모달, 빈 상태, 로딩·토스트
2. **P1 핵심 사용 흐름**: 홈 → 루틴 완료 → 타이머 → 생성·편집 → 주간 회고
3. **P2 탐색 화면**: 통계, 목표, 나무, 테마, 소모임
4. **P3 계정·예외 화면**: 인증, 프로필, 알림, 오류·빈 데이터 상태

## 발견된 UX 정리 포인트

- 습관·개인 루틴·신앙 루틴 생성 화면에 반복되는 패턴이 많아 공통 폼 섹션으로 통합할 여지가 크다.
- 화면마다 직접 작성한 `<button>`과 공통 `Button`이 섞여 있어 크기·눌림·접근성 상태가 달라질 가능성이 있다.
- 긴 화면은 월간 목표 생성, 주간 회고, 루틴 생성 폼이다. 단순한 시각 변경보다 단계·섹션 구조 재설계가 우선이다.
- 카드가 핵심 레이아웃 수단이지만 일부 화면은 카드 안에 카드가 중첩되어 정보 위계가 흐려질 수 있다.
- 손그림 스타일은 브랜드·완료 보상·빈 상태에 강하게 적용하고, 입력·통계·설정은 선명한 사용성을 우선하는 편이 안전하다.
