### 숫자와 근거의 일관성

현재 실적과 시간 후보를 저장하는 최종 함수에서 근거를 다시 검사한다. 알려지지 않은 수치를 임의로 `known` 또는 `estimate`로 바꾸는 것을 막고, 지원하는 수량 표현에서는 단위와 기간 환산도 비교한다. 예를 들어 1시간→60분은 허용하지만 2분→2시간, 프로젝트 2개→책 2권은 차단한다. 숫자가 없는 서술형 경험을 점수로 강제하지 않는다.

이는 제한된 문장·수량 검증이지 모든 자연어의 의미적 함의를 증명하는 시스템은 아니다. 미지원 표현과 복잡한 참조까지 해결했다고 주장하지 않는다. 대화 문구·고정 선택지·모델·공급자 설정·프롬프트는 변경하지 않았다.

### 일간 횟수는 시간 지도와 별개

이미 사용자가 말한 한도만 검사하며 생활 시간표 입력을 강제하지 않는다. 내부 요일별 시간·횟수 배열을 함께 배치 검사에 전달한다. 각 실행은 1회로 계산하고, 탐색 한도 초과는 가능하다고 단정하지 않는다. 실제 시계 시간 배치나 임의의 여러 행동 묶기까지 지원한 것은 아니다. 공개 `parseGoalCapacity` 결과는 기존 4개 필드 형태를 유지했다.
