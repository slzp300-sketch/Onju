## 9개 유형별 수정

| 유형 | 보완한 동작 | 함께 확인한 경계 |
|---|---|---|
| 간접 거절 | `읽겠다는 뜻은 아니었어`, `not committing`을 목표 확정으로 취급하지 않음 | 긍정·부정 대조, 좁은 수치 인용과 전체 발언 인용 모두 검사 |
| 강사·멘토 등 타인 수치 | 강사·멘토·코치 등 타인 정보가 본인의 현재 수준으로 저장되지 않도록 주체 구분 | 본인·타인 정보의 발언 순서를 바꾸어도 각 절을 분리 |
| 뒤에 붙은 변경 조건 | `12주로 늘릴게, 야근이 끝나면`, `only after ...`를 현재 즉시 변경으로 처리하지 않음 | 조건을 앞/뒤로 이동한 경우와 명시적인 현재 변경을 대조 |
| 같은 문장의 본인 정보 과잉 차단 | `남편은 책 5권이고 나는 책 2권`에서 본인의 2권을 독립 처리 | 타인의 5권은 계속 차단, 반대 어순도 검사 |
| 대조로 부정된 수치 | `30 minutes per week, not 2 hours`에서 부정된 2시간을 저장하지 않음 | 본인이 명시한 30분은 기록 가능 |
| 연결된 보류 의사 | `5 books sounds good, but don't set it yet`의 보류를 앞선 목표 후보와 연결 | 목표는 확정하고 일정만 미정인 별도 필드와 구분 |
| 제외 요일 | 일간 실행량에 포함 요일에서 제외 요일을 뺀 실제 일수 적용 | 주말 제외 매일 1편 = 주 5편, 8주 40편. 주간 총량을 중복 배수로 계산하지 않음 |
| 복합 시간 예산 | 시간+분 합산, 단위가 다른 범위, 영어 하이픈 세션 표현, half an hour 계산 | 주당 1시간 30분=90분, 30분~1시간=30~60분, three 20-minute sessions=60분/주, half an hour daily=210분/주 |
| 영어 목표 유지 선택 | 명시적 영어 목표 유지·첫 주 도전 선택도 한국어와 같은 동의 검증 사용 | 질문·거절·인용·조건·미확정은 동의가 아님. 동의해도 0분 및 수치 예산 상한을 우회하지 못함 |

복합 시간 관련 원래 실패는 `goal_capacity_unresolved`로 **초안을 차단하고 있던 상태**였다. 한도를 무제한으로 허용했던 오류가 아니라, 계산 가능한 표현을 해석하지 못해 불필요한 확인과 부정확한 오류 분류가 발생한 문제다. 보완 후 계산된 상한 초과는 `goal_capacity_conflict`로 차단한다.

## 코드 구조

- `goalEvidenceScope.ts`: 주체 전환, 간접 거절, 대조 부정, 전후 조건, 연결된 보류 의사를 공통 검사한다. 명사·숫자만 추출한 모델 후보가 주변 부정·조건을 우회하지 않도록 한다.
- `goalIntakeEvidence.ts`: `goalFeasibilityIsAccepted`에서 한·영 선택 의사를 공통 검증한다.
- `goalBrief.ts`: 위 선택 검증을 상태 변경에 연결한다. 기존 확정 데이터 보존 및 오류 계약을 유지한다.
- `goalDays.ts` 신규: 일간 수량의 포함·제외 요일 집합을 계산한다. 휴일 달력이나 일정 생성기가 아니다.
- `goalQuantity.ts`: 일간 실행량을 공통 요일 집합으로 환산한다.
- `goalCapacity.ts`: 원문을 보존한 파싱용 사본에서 표현 정규화, 시간 단위 합산·범위 및 횟수 계산을 수행한다. 일부 시간 단위만 읽고 임의의 상한을 만들지 않도록 남은 단위를 검사한다.
- `web-mvp/scripts/goal-intake-meaning.test.mjs` 신규: 변형·대조 회귀 검사 **141개**.
- `web-mvp/scripts/verify-offline.mjs`: 원래 6차 진단을 전체 무료 검사에 추가해 **24개 검사 묶음**으로 확장했다.

모델, 공급자 설정, 프롬프트, DB 스키마, 화면 및 고정 대답 문구는 이번에 변경하지 않았다. 모델 응답에 대한 저장·계산 검증 계층을 보완한 것이다.

## 해석 범위와 비용

로컬 검사는 외부 네트워크 차단과 공급자 환경변수 제거를 적용한다. 이번 **공급자 API 호출 0회 / 추가 모델 API 비용 $0**이다. 이는 이번 오프라인 검사에 관한 수치이며 Codex 사용 요금이나 과거·운영 전체 비용을 합산한 것이 아니다.

이 계층은 보수적인 패턴·주체 사전 기반 검증으로, 모든 자연어 의미를 이해하는 범용 파서가 아니다. 지원하지 않는 휴일 제외, 요일 범위, 일부 영어 수사·약어, 서로 충돌하는 예산은 확정 수치로 추정하지 않고 확인을 요구한다. 기존 95명은 가상 설정이며 실제 사용자 만족도, 모델 추출 정확도·응답 속도·대화 품질, 운영 웹 E2E나 글로벌 출시 준비 완료를 입증하지 않는다.

6차 기본 여정 122개 발언은 상당 부분 템플릿을 공유한다. 기존 6차 에이전트 경로 11개는 실제 capture 처리 후 의도적으로 중단하는 모의 검사다. 위 추가된 완료 경로 1개와 구분한다. 유료 평가 29개 시나리오·59개 발언은 실행 계획만 준비하며 실제로 호출하지 않는다. 운영 배포 및 실제 모델 품질 평가는 별도 범위로 남긴다.
