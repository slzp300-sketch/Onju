## 두 번의 확인

1차: 안내→UI→클라이언트→서버→DB 관계→로컬 저장 키를 대조했다. 세션 데이터, 내부 처리 캐시, 대기 큐, 알림 전달 기록, 삭제 방지 기록과 외부 보관을 구분했다.

2차: PostgreSQL/WASM·실제 메모리 핸들러 모의 경계·React DOM·실제 전송 큐의 합성 완료·390px 브라우저로 소유권/실패/재시도/삭제 경쟁을 확인했다. 첫 통합 실행에서 구 안내 문구에 고정된 테스트와 Fast Refresh 파일 구성 문제가 발견되어 수정한 뒤 최종 통합 실행을 다시 통과했다.
