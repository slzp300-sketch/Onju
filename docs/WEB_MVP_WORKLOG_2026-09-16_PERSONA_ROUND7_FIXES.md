원래 67개 실패 중 복합 시간 관련 6개 초안 조건은 이미 `goal_capacity_unresolved`로 안전하게 차단되고 있었다. 이번에는 계산된 한도 초과를 `goal_capacity_conflict`로 정확히 처리하도록 보완했다. 반면 `1½ hours`의 120분 오독은 실제로 주 100분 초안을 해당 한도 검사에서 통과시키던 문제였고, 90분으로 계산해 차단하도록 수정했다.

## 코드 구성

- `goalEvidenceScope.ts`: 연결된 철회, 조건, 주체, 부정·의심 검사와 현재 수준 전용 `goalBaselineIsCurrent`를 제공한다. 미래 목표를 현재 실적 검사 때문에 일괄 차단하지 않는다.
- `goalBrief.ts`: 현재 수준·가용 시간·우선순위 저장에 해당 검증을 연결한다. 짧은 시간 근거의 원래 발언 절도 확인한다. 기존 상태의 불변성 및 원자적 업데이트를 유지한다.
- `goalIntakeEvidence.ts`: 영어 기간·요일 시간 근거를 인식하며, 실행 이력과 가용 시간의 구분에 study/practice를 포함한다.
- `goalNumberNotation.ts` 신규: 수량·시간 계산에 공통 분수 정규화를 제공한다. 저장 원문은 수정하지 않는다.
- `goalQuantity.ts`: 공통 숫자 정규화, 격일 평균, 명시적 반복 요일을 적용한다.
- `goalDays.ts`: 한국어 포함 범위와 명시적 영어 반복 요일을 처리한다. 휴일 달력이나 실제 일정 생성기는 아니다.
- `goalCapacity.ts`: 분수·회당 문법을 정규화하고, 겹치지 않는 요일별 예산을 합산한다. 일부 숫자만 읽거나 겹치는 일수를 더한 임의의 한도를 만들지 않는다.
- `web-mvp/scripts/goal-intake-decisions.test.mjs` 신규: 변형·대조·상태 보존 회귀 검사 **156개**.
- `web-mvp/scripts/verify-offline.mjs`: 7차 고정 진단을 추가해 전체 무료 검사를 **25개 묶음**으로 확장했다.

모델, 공급자 설정, 프롬프트, DB 스키마, 화면 및 고정 답변 문구는 이번에 변경하지 않았다. 저장 검증과 결정론적 계산을 보완한 것이다. 정규식·사전 기반 보수적 검증이라는 한계는 남아 있으며 범용 자연어 이해 엔진으로 바뀐 것은 아니다.

## 비용과 남아 있는 검증 한계

외부 네트워크 차단과 공급자 환경변수 제거를 적용해 **공급자 API 호출 0회 / 이번 추가 모델 API 비용 $0**으로 검사한다. 이 수치는 이번 오프라인 검사의 추가 비용이며 Codex 요금이나 과거·운영 전체 비용을 합산한 것은 아니다.

125명은 가상 설정, 실제 참여자는 0명이다. 7차의 모의 capture 경로 13개는 처리 결과를 읽고 중단하는 진단이며, 이번에 새로 추가한 완결 경로 2개와 구분한다. 실제 모델 대화 품질, 추출 정확도, 응답 속도, 만족도, 운영 웹 E2E 및 글로벌 출시 준비 완료를 검증한 결과는 아니다.

격일 값은 시작일 없는 장기 주간 평균이다. 실제 특정 주의 3회/4회 일정 배치를 보증하지 않는다. 휴일·지원하지 않는 요일 범위·겹치는 예산·일부 분수 문법은 임의로 확정하지 않고 확인을 요구한다. 원래 사용자 근거는 그대로 보존한다.

실제 모델 품질 평가는 별도 비용 승인 범위이며, 이번에는 배포하지 않았으므로 운영 사이트에 이 수정이 적용됐다고 안내하지 않는다.
