# 온주 작업로그 — 원문과 동일한 발언으로 실제 배포본 비교

## 요청과 범위

사용자가 제공한 운동 코칭 문서의 동일한 사용자 텍스트를 온주에 입력하고, 원문 수준의 상세한 응대가 나오는지 검증했다. 마지막 파일 저장 요청을 제외한 코칭 발언 3개를 두 배포 에이전트에 각각 입력했다. 원문의 AI 답변은 주입하지 않았다.

## 결과

**기본 배포본과 시험용 배포본 모두 원문 수준의 구체성 기준 미달.**

- 기본 배포본: 세 번 모두 기간 확인. 상세 사용자 정보 이후에도 응답 107자.
- 시험용 배포본: 현재 동작 수행 수준과 약점을 반영했으나 응답 213자에서 기간 질문으로 종료.
- 원문의 같은 단계 응답은 2,489자로 실행 방법·주간 구성·기록 및 조정 방법을 제시했다. 길이만으로 품질을 판단한 것은 아니다.
- 기간 미제공으로 확인 자체는 타당하지만, 설명과 조건부 실행 안내까지 막힌 것처럼 보이는 흐름을 관찰했다. 정확한 내부 원인은 배포 소스/설정 대조 전에는 확정하지 않는다.
- 원문의 확인되지 않은 기간·장비·건강 수치·자동 알림 약속은 재현 목표에서 제외했다.

## 시험 버전과 한계

- 배포된 `onju-agent-v2`: 응답 진단 모델 `gpt-5.6-sol`, 빌드 식별 정보 미제공.
- 배포된 `onju-agent-v3`: `gpt-5.6-terra` / `gpt-5.6-sol`, operatingSpecVersion `2026-09-11`.
- **9월 17일 로컬 최신 수정은 미배포 상태이며 이번 실제 호출 대상이 아니다.** 로컬 직접 호출용 OpenAI 키가 표준 환경 파일/현재 환경에 없었다. 서버 키를 추출하거나 다른 제공자로 몰래 바꾸지 않았다.
- 브라우저 화면 검사가 아니라 실제 웹 API 대조 시험이다. 독립 테스트 세션을 사용했다.
