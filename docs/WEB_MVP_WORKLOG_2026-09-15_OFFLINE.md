# 온주 작업로그 — 유료 검증 보류와 무료 개발 마무리

작성일: 2026-09-15 (KST)

## 이번 결정

사용자 요청: 개발할 수 있는 부분을 먼저 마무리하고, 비용이 드는 실제 AI 품질 검증은 이후에 진행한다.

이번 개발 범위는 비용·전환 리포트의 정확성, 오프라인 반복 검증, 유료 평가 실행 조건 정비다. 실행 모델·대화 프롬프트 변경이나 공급자 교체는 이번 범위에 포함하지 않았다.

## 1. 비용·전환 리포트 보완

- 비용과 이벤트를 같은 UTC 시작 이상~종료 미만 범위로 조회하도록 통일했다. 일별 뷰로 부분 날짜 비용이 누락되는 문제를 수정했다.
- 기간 내 세션 ID를 중복 제거한다. 단계별로 서로 다른 세션의 단순 숫자를 나누던 전환율을 목표 설계 시작 세션의 순차 전환으로 변경했다.
- 목표 시작 전에 이미 확정한 이벤트, 시작 기록이 없는 재방문 사용자의 실행을 새 목표 전환율에 섞지 않는다.
- 일일 점검·실험·기타 활동은 순서 강제 없이 별도 활동 표에 표시한다.
- 국가·언어 필터를 비용과 전환에 함께 적용하고 모델·작업별 세부 금액을 제공한다.
- 미산정 호출이 있으면 전체 비용과 평균은 `null/미산정`이다. 산정 가능한 금액 합계는 별도로 유지한다.
- 입력·출력 사용량 누락을 무료 호출로 계산하던 문제를 수정했다. 모델명 접두어가 같아도 mini/nano/pro 등 다른 모델에 기본 모델의 단가를 적용하지 않는다.
- 재시도율은 재시도한 호출 수 ÷ 전체 기록 호출 수다. 추가 시도 횟수는 따로 보여준다.
- 모델 호출, 사용자 메시지, 익명 브라우저 세션을 서로 다른 단위로 명시한다.
- 서버가 작은 페이지를 반환하는 상황, 정확한 전체 건수, 안정적인 시각·ID 정렬, 조회 중 변화와 누락 오류 처리를 추가했다.
- 가상 데이터와 로컬 JSON으로 네트워크·키 없이 Markdown/JSON 리포트를 생성할 수 있다. 최종 리포트에는 대화 원문·세션 ID·키를 내보내지 않는다.

주요 파일:

- `web-mvp/scripts/metrics-report-lib.mjs`
- `web-mvp/scripts/metrics-report-source.mjs`
- `web-mvp/scripts/report-metrics.mjs`
- `supabase/functions/_shared/onjuMetrics.ts`

## 2. 유료 평가 실행 조건 정비

- `eval:agent`, `eval:adaptive`, `eval:english`는 기본 실행 시 계획만 출력한다. 기본 경로는 환경파일과 API 키도 읽지 않는다.
- 실제 실행은 `--live`, `ONJU_ALLOW_PAID_EVALS=1`, `--max-turns`가 함께 필요하다. 전체 선택 시나리오가 턴 한도를 넘으면 호출 전에 중단한다.
- 한 시나리오를 턴 중간에 잘라 평가하지 않는다. 사용자 턴 제한은 모델 호출 수나 달러 상한을 보장하지 않으므로 별도로 명시했다.
- 이전 A/B 및 품질 평가 스크립트도 유료 실행 조건을 명시해야 호출한다.
- 유지 중인 5개 평가 세트 **29개 시나리오 / 59개 사용자 턴**의 계획과 fixture 해시를 준비했다. 이 숫자는 실제 모델 평가 실행/통과 건수가 아니다.
- 향후 실제 실행 요청에는 독립 테스트 세션, 세션 토큰, 턴 ID가 함께 전달된다.

- 웹 TypeScript 검사, 비용 모듈 strict TypeScript 검사 통과
- 웹 production build 통과
- ESLint 및 knip 통과
- 가상 비용 리포트 생성 및 유료 평가 계획만 출력하는 CLI 검증 통과

검사 도구에서 발견한 설치 경로·TypeScript 6 실행 옵션 차이는 수정했다. 상위 디렉터리에 설치된 의존성도 정상적으로 찾는다.

## 비용과 완료 범위

| 항목 | 이번 작업 |
|---|---|
| 외부 모델 API 호출 | 0회 |
| 온주 개발·테스트의 추가 모델 API 비용 | **$0** |
| 실제 DB 조회·데이터 변경 | 없음 |
| 운영 배포 | 없음 |
| 실제 모델 품질 평가 | 사용자 요청에 따라 보류 |

위 비용은 이번 온주 API 호출 기준이다. Codex 이용료, 기존 호스팅 구독, 과거 개발 비용의 총합을 뜻하지 않는다. 이전 단일 실행의 비용을 서비스의 확정 평균 채팅 단가로 일반화하지 않는다.

이번 범위의 무료 개발·회귀 검사는 완료했다. 실제 한국어·영어 대화의 자연스러움, 모델 응답속도, 라이브 API 연동, 공급자 청구액과 원장 대조는 이번 오프라인 결과로 보증하지 않는다. 실제 모델을 사용하는 최종 검증과 배포 확인은 이후 단계에서 수행한다.

기존 웹 번들 500 kB 초과 경고는 빌드 로그에 남아 있다(약 533 kB, gzip 약 155 kB). 이번 운영 스크립트는 브라우저 번들에 포함되지 않는다.

운영 지표의 보존 범위에도 한계가 있다. 과거 미수집 호출, 측정 쓰기 실패, 응답을 못 받은 유료 요청, 삭제·만료 세션의 행은 빠질 수 있어 리포트를 전체 과거 청구액으로 표현하지 않는다.
